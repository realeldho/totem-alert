# Totem Alert

A lightweight client-side Minecraft Fabric mod that alerts you when a Totem of Undying is not equipped in your off-hand.

## ✨ Features

- 🔴 Red "Totem Not Equipped" alert
- 🟨 Totem icon with a red slash
- 🎨 Choose between Text and Icon alert modes
- 📏 Adjustable alert size from 50% to 200%
- 🖱️ Full-screen drag-and-drop position editor
- 💾 Settings automatically saved between Minecraft launches
- ⌨️ Right Shift toggle key
- ⚙️ O opens the Totem Alert settings
- 🧩 Optional ModMenu integration
- 🎮 Client-side mod

## 🎮 Controls

| Action | Default Key |
|---|---|
| Toggle Totem Alert | Right Shift |
| Open Settings | O |

Both keybinds can be changed through Minecraft's Controls menu.

## ⚙️ Settings

Totem Alert lets you customize:

- Alert style
- Alert size
- Alert position
- Enabled/disabled state

Settings are automatically saved to:

```text
.minecraft/config/totem-alert.json
